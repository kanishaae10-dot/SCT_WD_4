
# TaskFlow - To-Do Web App

## About
TaskFlow is a responsive To-Do Web Application developed using HTML, CSS, and JavaScript. It helps users organize daily activities, manage task lists, set deadlines, and track their progress.

## Features
- Add, edit, and delete tasks
- Mark tasks as completed or pending
- Organize tasks into Personal, Study, Work, and Other lists
- Set a date and time for tasks
- Search tasks by name
- Filter tasks by completion status
- Display total, pending, and completed task counts
- Save tasks in browser localStorage
- Responsive design for mobile and desktop
- Highlight overdue tasks

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using the Live Server extension.
4. Add and manage your tasks in the browser.
